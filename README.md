# بوت «مركز الشفاء الطبي» — خدمة الأسئلة الشائعة (FAQ Bot)

بوت ذكاء اصطناعي بسيط يعمل من سطر الأوامر (CLI) للرد باللغة العربية على استفسارات زوار **«مركز الشفاء الطبي»** في صنعاء اعتماداً **حصراً** على ملف الأسئلة الشائعة (`faq.json`) دون اختراع أي إجابات أو تقديم نصائح طبية قد تضر المريض.

---

## الفكرة والتصميم (لماذا هذا الحل؟)

- **البساطة والدقة أولاً:** نظراً لأن ملف الأسئلة الشائعة يحتوي على 12 سؤالاً فقط (~1,100 توكن)، تم تمرير محتوى الملف مباشرة ضمن `system_instruction` للنموذج بدلاً من بناء قاعدة بيانات متجهات (Vector DB / RAG) معقّدة. هذا النهج أسرع، أقل عرضة لأخطاء الاسترجاع، ولا يحتاج أي بنية تحتية إضافية.
- **منع الهلوسة والاختراع:** تم ضبط `temperature = 0.0` مع تعليمات نظام صارمة تُلزم البوت بالاعتذار وإعطاء رقم التواصل (`777000123` / `01-445566`) فوراً إذا كان السؤال خارج الملف أو يطلب تشخيصاً أو دواءً.

---

## الأدوات والنماذج المستخدمة

- **اللغة:** Python 3.10+
- **المكتبة الرسمية:** [`google-genai`](https://pypi.org/project/google-genai/) + `python-dotenv`
- **النموذج:** `gemini-3.5-flash-lite` عبر [Google AI Studio](https://aistudio.google.com/) (الخطة المجانية — التكلفة الفعلية 0 ريال).
- **أدوات مساعدة:** الاستعانة بـ Gemini للمساعدة في صياغة هيكل الكود ومراجعة ملف الأسئلة والتوثيق.

---

## هيكل المشروع

- `faq.json` — ملف الأسئلة الشائعة لمركز الشفاء الطبي (12 سؤالاً وجواباً تشمل الدوام، العنوان، الأقسام، الأسعار، الحجز، المختبر، الأشعة، الطوارئ، والتأمين).
- `bot.py` — كود البوت الرئيسي وواجهة سطر الأوامر (CLI).
- `test_bot.py` — سكربت اختبار تلقائي للأسئلة الخمسة يحفظ النتائج والتوكنز الفعلية في `test_results.md`.
- `requirements.txt` — المكتبات المطلوبة.
- `.env.example` — نموذج لإعداد مفتاح `GEMINI_API_KEY`.

---

## خطوات التشغيل

1. **استنساخ المشروع وإنشاء بيئة افتراضية:**
   ```bash
   git clone https://github.com/Alqasem-f/alshifa-medical-bot.git
   cd alshifa-medical-bot
   py -m venv .venv
   # على ويندوز:
   .venv\Scripts\activate
   # على لينكس/ماك:
   source .venv/bin/activate
   ```

2. **تثبيت المكتبات:**
   ```bash
   py -m pip install -r requirements.txt
   ```

3. **إعداد مفتاح Gemini API المجاني:**
   - انسخ الملف `.env.example` إلى `.env`:
     ```bash
     copy .env.example .env
     ```
   - ضع مفتاحك من [Google AI Studio](https://aistudio.google.com/apikey) داخل `.env`:
     ```env
     GEMINI_API_KEY=AIza...
     GEMINI_MODEL=gemini-3.5-flash-lite
     ```

4. **تشغيل البوت من سطر الأوامر:**
   ```bash
   py bot.py
   ```

5. **تشغيل اختبار الأسئلة الخمسة وتوليد جدول النتائج:**
   ```bash
   py test_bot.py
   ```
   سيقوم السكربت باختبار 5 أسئلة (3 من الملف و2 خارج الملف) وحفظ الجدول الكامل مع عدد التوكنز الفعلي في ملف `test_results.md`.

## حساب التكلفة التقريبية لكل 1,000 سؤال

بناءً على القياس الفعلي للتوكنز من الاختبار أعلاه وعلى التسعير الرسمي لنموذج **`gemini-3.5-flash-lite`** في [صفحة تسعير Gemini API](https://aistudio.google.com/docs/pricing):

- **الخطة المجانية (Free Tier):** **$0.00** (مجانية بالكامل ضمن الحدود اليومية للاستخدام).
- **الخطة المدفوعة (Paid Tier):**
  - سعر توكنز الإدخال (Input): **$0.30** لكل مليون توكن.
  - سعر توكنز الإخراج (Output): **$2.50** لكل مليون توكن.

### المتوسط الفعلي لكل سؤال (من التجربة):
- **متوسط توكنز الإدخال:** `1,199` توكن لكل سؤال (تعليمات النظام + ملف `faq.json` + سؤال الزائر).
- **متوسط توكنز الإخراج:** `70` توكن لكل سؤال (إجابة عربية مختصرة وواضحة).

### الإجمالي لكل 1,000 سؤال:
- **إجمالي الإدخال:** `1,000 × 1,199 = 1,199,000` توكن ← `1.199 × $0.30 = $0.3597`
- **إجمالي الإخراج:** `1,000 × 70 = 70,000` توكن ← `0.070 × $2.50 = $0.1750`
- **التكلفة الإجمالية التقريبية لكل 1,000 سؤال:** **`$0.5347` (حوالي 53 سنتاً أمريكياً فقط)**، أي أقل من **0.00054 دولار** للسؤال الواحد.
